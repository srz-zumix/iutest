#define IUTEST_MATCHER(name, description)
 Define a polymorphic matcher. The body can use arg, arg_type and result_listener (supporting streaming, IsInterested() and stream()). Descriptions can use negation.

詳解

Matchers

覚え書き
Eq, Equals, Ne, Lt, Le, Gt, Ge and TypedEq copy their expected values. Use std::ref/stdcref (C++11) for live references or non-copyable values; the referenced object must outlive the matcher. Code relying on implicit reference retention must opt in explicitly. Arrays are still referenced, and pointer pointees are not owned by these matchers.
